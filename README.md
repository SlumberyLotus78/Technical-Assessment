# Technical-Assessment
This repository is technical assessment for a Data Engineer position.

It is an end-to-end data engineering pipeline, covering all key stages from data extraction and transformation to analysis and visualization.


## Work Plan

The project scope, proposed structure, and implementation phases are described in the [implementation plan](PLAN_IMPLEMENTACION_ES.md).

## Development Environment

- Python 3.12.4, specified in `.python-version`.
- Local virtual environment in `.venv`.
- Python and pip installations verified within the virtual environment.
- Private configuration files and generated files excluded using `.gitignore`.
